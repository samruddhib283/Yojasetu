# Yojasetu  Over 13,000+ government schemes exist in India, yet 
65% of eligible citizens miss out due to lack of 
awareness and complex applications (PRS India).
 • Our AI-powered Scheme Recommender simplifies this 
with a chatbot that collects user details, provides 
personalized scheme suggestions, and offers a step
by-step video guide for easy application.
 • ✅ Example: A farmer earning ₹1.5 lakh annually may 
miss PM-KISAN benefits. Our chatbot analyzes user 
data, suggests relevant schemes, and provides a video 
guide, ensuring easy access to benefits

 This project aims to develop an AI-powered scheme 
recommender system that simplifies scheme 
discovery, provides personalized recommendations, 
and offers video-based assistance for a seamless 
application process, ensuring greater accessibility and 
participation
